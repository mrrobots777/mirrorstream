# Plan 3 — Segurança: portão de credencial, emissor e rate limit

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An addon URL without a valid per-install credential gets **404** (not 401 — 404 does not confirm an addon exists), `/install` only mints links for the owner, and the rate limiter can no longer be reset by filling its key table.

**Architecture:** The credential rides in the path segment that **already exists** on all four Stremio routes (`/:config/...`, `core/nomes.js:154-157`), so **no route pattern changes** — only a validation gate ahead of them. `/install` becomes an issuer guarded by a master key. The rate limiter's `clear()` bypass becomes LRU eviction.

**Tech Stack:** Node ≥18, CommonJS, Express 5, existing `sqliteCache` for token storage, no new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-03-fontes-e-seguranca.md` — section "Frente 3".

## Global Constraints

- Node local is **18** (`/usr/bin/node`). Never `/tmp/node-v22.*`.
- **CommonJS only.** `mirrorstream/` and `mirrorview/` keep **zero code of the other product** — each builds its own gate; do not create a shared module across them.
- **Every new env var and route MUST be registered** in `core/nomes.js` (`VARIAVEIS` with `segredo: true`, and `ROTAS` for routes) — `test/mirror.test.js` fails otherwise, and env vars marked `segredo: true` must never print their value (`/health → credenciais` shows only `definida`/`ausente`).
- **Migration is a clean cut** (owner's decision): after deploy, `https://host/manifest.json` **404s immediately**. No grace window, no degraded legacy mode.
- Every edit under `mirrorview/` requires: `node tools/gerar-branch-mirrorview.js`.
- Barrier (the three directories CI runs): `node --test test/ mirrorstream/test/ mirrorview/test/`.
- **Never commit without being asked.** Nothing in this repo has been committed by this effort so far.

## Review Focus

| Input / failure mode | Expected behaviour | Test that pins it |
|---|---|---|
| Request to `/manifest.json` with **no** segment | **404**, body does not mention "addon" | Task 1 Step 1 |
| Request to `/:config/manifest.json` with a bogus segment | 404 | Task 1 Step 1 |
| Request with a **valid** credential | 200, identical manifest | Task 1 Step 1 |
| A revoked token (removed from store) | 404 on next request | Task 1 Step 1 |
| Someone reads `/install` without the master key | No link, no token minted | Task 2 Step 1 |
| An existing token minted before the cut | Works after deploy (only old *bare* URLs die) | Task 2 Step 1 |
| Key table filled past 20 000 | **Oldest** evicted; the attacker's own recent counter **survives** | Task 3 Step 1 |
| Rate-limit entry already past its window | Removed regardless of table pressure | Task 3 Step 1 |
| `/health`, `/metrics` still answer without a credential | Yes — monitoring must not break | Task 1 Step 1 |

### Task 1: The credential gate

**Files:**
- Create: `mirrorstream/src/lib/portao-instalacao.js`
- Create: `mirrorview/src/lib/portao-instalacao.js` (own copy, no shared import)
- Modify: `mirrorstream/src/core/nomes.js` — add `ROTAS.emitirToken`, `VARIAVEIS.INSTALACAO_SEGREDO` (`segredo: true`), `VARIAVEIS.INSTALACAO_MESTRA` (`segredo: true`)
- Modify: `mirrorview/src/core/nomes.js` — same
- Modify: `mirrorstream/src/server.js` — register the gate **before** the Stremio routes
- Modify: `mirrorview/src/server.js` — same, plus the `/nuvio/*` routes
- Test: `test/portao-instalacao.test.js` (create)

**Interfaces:**
- Consumes: `sqliteCache` (already used for caches); `ROTAS`/`VARIAVEIS`/`ENV` from `core/nomes.js`.
- Produces:
  - `montaCredencial(segredo, token) -> string` — `"${segredo}.${token}"`
  - `leCredencial(bruto) -> { segredo, token } | null` — splits on the **first** `.`; malformed → `null`
  - `portao(req, res, next) -> void` — Express middleware; valid → `next()`, otherwise `res.status(404).json({ statusCode: 404, message: "Not found" })`
  - `estaIsenta(patho) -> boolean` — allowlist of routes that stay open without a credential
  - `emitirToken() -> Promise<string>` — mints and persists a bare token; Task 2's `emite` calls it
  - `tokenValido(credencial) -> Promise<boolean>` — reads the store; a revoked token returns `false`
  - `revogarToken(token) -> Promise<void>` — removes it from the store

**Route positions that must be gated** (all already exist; nothing is created):

| mirrorstream | mirrorview |
|---|---|
| `ROTAS.manifesto` `/:config/manifest.json` | same |
| `ROTAS.streamsStremio`, `ROTAS.catalogoStremio`, `ROTAS.metaStremio` | same |
| bare routes served by `app.use("/", sdkRouter)` (`server.js:1791`) | same |
| — | `ROTAS_NUVIO.manifesto/catalogo/meta/stream` (`nomes.js:172-175`) |

**Must stay open:** `GET /health`, `GET /metrics`, static assets, `GET /dashboard`, `GET /tv`.

- [ ] **Step 3: Implement `portao-instalacao.js` in `mirrorstream/src/lib/`**

`montaCredencial`/`leCredencial` are pure. `tokenValido` reads the SQLite store (`mirror-tv:instalacao:<token>` pattern already used by caches) with a long TTL (recommend **365 dias** — an install must not self-destruct). `portao` reads `req.params.config` **and** the bare path: if the request has no `:config` segment at all, it is invalid — that is what closes `https://host/manifest.json`.

`estaIsenta(patho)` holds the explicit allowlist (`/health`, `/metrics`, `/dashboard`, `/tv`, static). Keep it a list of prefixes, not a regex — a permissive regex here is how the gate silently stops gating.

- [ ] **Step 4: Register the env vars and route**

In **both** `core/nomes.js`: `INSTALACAO_SEGREDO` and `INSTALACAO_MESTRA` under `VARIAVEIS` with `segredo: true`; `emitirToken: "/admin/emitir-token"` under `ROTAS`. Read via `ENV` (never `process.env.X` directly — the registry test fails).

- [ ] **Step 5: Wire the gate in `mirrorstream/src/server.js`**

`app.use(portao)` placed **after** the exempt routes are defined and **before** `ROTAS.manifesto` (line 1265) and before `app.use("/", sdkRouter)` (line 1791). Order is the whole task — a gate registered after a route never sees that route.

### Task 2: `/install` becomes the issuer

**Files:**
- Modify: `mirrorstream/public/install.html:283-291` and `mirrorview/public/install.html:227-233`
- Modify: `mirrorstream/src/server.js` (route `ROTAS.emitirToken`) and `mirrorview/src/server.js`
- Test: `test/instalacao-emissora.test.js` (create)

**Interfaces:**
- Consumes: Task 1's `emitirToken()`, `montaCredencial()`, and `ENV.INSTALACAO_MESTRA`.
- Produces: `emite(chaveMestra) -> { credencial, token, url } | null` — returns `null` for any key that is not `INSTALACAO_MESTRA`; also `GET /install?chave=<mestra>` renders the page with a **personalized** link, and `POST /admin/emitir-token` (header-gated, same pattern as `POST /admin/limpar-cache`) returns `{ success: true, data: { credencial, url } }` for the owner to distribute.

**Two defects this task must fix — both measured:**

1. `install.html:231` and `:287` build the install link as `'stremio://' + new URL(clean).host + '/manifest.json'`. **`.host` discards the path**, so the Install button would emit a credential-less URL and walk straight through the gate. It must emit the full path.
2. `install.html:229`/`:285` show `clean + '/manifest.json'` as the copyable manifest — same problem.

### Task 3: Rate limiter stops being resettable

**Files:**
- Modify: `mirrorstream/src/server.js:1159` and `mirrorview/src/server.js:1343`
- Test: `test/rate-limit-evicao.test.js` (create)

**Interfaces:**
- Consumes: nothing new.
- Produces: `eviciona(mapa, agora, maxChaves) -> number` — exported from `server.js` **or** (preferred, since `server.js` is 2 000 lines and importing it boots the app) from a small `mirrorstream/src/lib/evicao.js` + `mirrorview/src/lib/evicao.js`.

**The bug:** when the map reaches `RATE_LIMIT_MAX_KEYS` (20 000), both servers call `rateLimitMap.clear()` — that wipes **everyone's** counter, including the attacker's. Filling the table resets the limit on demand.

- [ ] **Step 1: Write the failing test**

```js
const test = require("node:test");
const assert = require("node:assert");
const { eviciona } = require("../mirrorstream/src/lib/evicao");

test("encher a tabela NAO zera o contador de quem ja passou do limite", () => {
  const mapa = new Map();
  const agora = Date.now();
  // um atacante que ja estourou, ha 1s
  mapa.set("atacante:api", { start: agora - 1000, count: 181 });
  // 20.000 chaves antigas de outros IPs
  for (let i = 0; i < 20000; i++) mapa.set(`ip${i}:api`, { start: agora - 120000, count: 1 });

  eviciona(mapa, agora, 20000);

  assert.ok(mapa.has("atacante:api"), "a entrada recente nao pode ser apagada pela evicao");
  assert.equal(mapa.get("atacante:api").count, 181, "o contador nao pode ser zerado");
  assert.ok(mapa.size <= 20000, `tabela ficou com ${mapa.size}`);
});

test("entrada ja expirada sai mesmo sem pressao de tabela", () => {
  const mapa = new Map();
  const agora = Date.now();
  mapa.set("velha:api", { start: agora - 120000, count: 5 });
  mapa.set("nova:api", { start: agora, count: 1 });
  eviciona(mapa, agora, 20000);
  assert.equal(mapa.has("velha:api"), false, "expirada tem de sair");
  assert.equal(mapa.has("nova:api"), true);
});
```

- [ ] **Step 2: Run test to verify it fails**

Run: `cd /home/ubuntu/mirror && node --test test/rate-limit-evicao.test.js`
Expected: FAIL — `Cannot find module '../mirrorstream/src/lib/evicao'`

- [ ] **Step 3: Implement `eviciona(mapa, agora, maxChaves)`**

Two passes: (1) delete entries whose `start` is older than `RATE_LIMIT_WINDOW`; (2) if still over `maxChaves`, delete oldest-first until at or below. **Never `clear()`.** Evicting oldest-first is deliberate: the attacker's own entries are the *newest*, so their counter survives and keeps counting against them.

- [ ] **Step 4: Run test to verify it passes**

Run: `cd /home/ubuntu/mirror && node --test test/rate-limit-evicao.test.js`
Expected: PASS (2/2)

- [ ] **Step 5: Replace `clear()` in both servers**

`mirrorstream/src/server.js:1159` and `mirrorview/src/server.js:1343` — call `eviciona(...)` instead. Also add a **per-credential** bucket alongside the per-IP one: key `${credencial}:cred` with the same `RATE_LIMIT_MAX`, so one install hammering the server cannot consume another install's budget.

## Out of scope for this plan (stated, not forgotten)

- **Existing installs break on deploy.** Clean cut, owner's explicit decision. Distribute new links before deploying.
- **A legitimate user sharing their link still lets a cloner in.** The token is per-install and revocable — that is the mitigation, not prevention.
- **The plugin is unaffected** — it never calls our server (verified across `plugin/src`).
- **CORS (`Access-Control-Allow-Origin: *`, `mirrorstream/server.js:1170`) is not tightened here.** It is a real observation but tightening it can break the Stremio web client; it needs its own measured check against a real client before changing.
- Source quality, and live-TV coverage: Plan 1. Scraper timeout/retry standardization: Plan 2.
