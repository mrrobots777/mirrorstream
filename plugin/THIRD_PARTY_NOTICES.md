# Aviso de terceiros

## ShinoKai v2

O scraper `src/scrapers/animes/shinokai.js` adapta o fluxo do provedor ShinoKai v2 publicado em [kaminarizz/zeus-open-source](https://github.com/kaminarizz/zeus-open-source), sob licença MIT.

A adaptação foi reescrita para o runtime browser do Nuvio, usando Web Crypto em vez dos módulos Node.js. O projeto original continua sendo a referência de implementação do protocolo e dos endpoints; este plugin não copia credenciais de conta de usuário.
