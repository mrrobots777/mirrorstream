Instalação no Nuvio

Siga o passo a passo para adicionar o MirrorStream ao seu Nuvio.

  1. 1Acesse Settings → Plugins no Nuvio.
  2. 2Escolha Add repository URL.
  3. 3Cole a URL do repositório MirrorStream.
  4. 4Confirme. O plugin estará disponível na sua lista.

Repositório do Plugin

Use este endereço ao adicionar uma fonte no Nuvio.

https://mrrobots777.github.io/mirrorstream/
Importante

Adicione a URL base acima como repositório. Se uma versão antiga estiver em cache, remova e adicione o repositório novamente.

Como funciona?

O MirrorStream reúne fontes em um único plugin. Os resultados são organizados por qualidade e apresentados no Nuvio para você escolher o player.
